Dernière étape : connecte Supabase

  1. Crée un projet gratuit sur supabase.com.
  2. Dans « SQL Editor », colle le fichier supabase_schema.sql et lance-le (Run).
  3. Dans « Project Settings », onglet « API » : copie l'URL du projet et la clé publique (anon ou publishable).
  4. Colle-les en haut du script de ce fichier, à la place de COLLE_ICI_..., puis recharge la page.

Ne colle jamais la clé « service_role » dans ce fichier : elle donne tous les droits.

Pour essayer l'application sans Supabase, ouvre boutikguinee-demo.html.
